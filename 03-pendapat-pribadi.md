# Pendapat Pribadi tentang Day 1 Proyek Workshop

**Abdullah Naufal Syauqi, Kelompok Dreadout**

## Kesan Umum

Day 1 memberi manfaat yang banyak bagi saya sebagai mahasiswa TIK PNJ. Materinya tidak hanya teori: saya mengenal arah akademik yang bisa saya ambil (MBKM dan MSIB), belajar menggunakan AI dengan cara yang lebih terarah lewat prompt engineering, dan mulai memakai Git dan GitHub, alat yang akan terus saya pakai di dunia kerja.

## Manfaat yang Saya Rasakan

1. **Gambaran jalur karier dan akademik.** Dengan memahami MBKM dan MSIB, saya tahu bahwa ada kesempatan magang atau studi independen yang diakui sebagai SKS. Ini membantu saya merencanakan kuliah dan menyiapkan CV serta portofolio sejak awal.
2. **Cara memakai AI dengan lebih baik.** Saya belajar bahwa AI bukan sekadar "tanya lalu terima jawaban". Prompt yang jelas (Role, Task, Context, Format) menghasilkan jawaban yang jauh lebih tepat, dan hasilnya tetap harus saya periksa sendiri.
3. **Keterampilan inti seorang programmer.** Git dan GitHub dipakai luas di industri. Memahami alur working directory, staging area, dan repository membuat saya lebih siap bekerja dalam tim.
4. **Portofolio digital.** Repository ini adalah langkah pertama membangun profil GitHub yang bisa dilihat dosen, mitra industri, maupun perekrut.
5. **Kebiasaan mendokumentasikan.** Saya belajar bahwa mencatat dan merapikan proses belajar membantu saya mengulang materi dan menunjukkan perkembangan saya.

## Rencana Pemanfaatan ke Depan

- Rutin menyimpan tugas dan proyek kuliah di GitHub dengan commit yang jelas.
- Menulis `README.md` yang rapi di setiap proyek.
- Memakai AI sebagai asisten belajar dan membuat aplikasi dengan prompt terstruktur, tanpa melepaskan pemahaman saya sendiri atas kode yang dihasilkan.
- Mempertimbangkan MBKM dan MSIB dalam perencanaan studi dan karier, serta berkonsultasi dengan koordinator MBKM atau dosen pembimbing akademik.
- Mempelajari branch dan pull request agar siap berkolaborasi di proyek tim.

## Kendala dan Saran

- **Kendala:** Tidak ada kendala berarti. Penyampaian materi oleh pemateri sudah disertai arahan yang jelas, sehingga materi dan praktik mudah diikuti.
- **Saran:** Semoga di hari berikutnya ada praktik lanjutan tentang kerja tim di GitHub, seperti branch dan pull request.

## Penutup

Day 1 menjadi fondasi yang baik. Saya ingin menerapkan apa yang dipelajari dan terus mengembangkannya di hari-hari workshop berikutnya.
