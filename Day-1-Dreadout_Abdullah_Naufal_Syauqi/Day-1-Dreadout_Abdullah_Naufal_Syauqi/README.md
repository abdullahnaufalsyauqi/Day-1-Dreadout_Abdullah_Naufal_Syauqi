## Deskripsi Repository

Repository ini berisi dokumentasi kegiatan **Day 1 Workshop** yang diikuti oleh Abdullah Naufal Syauqi dari kelompok **Dreadout**. Isinya mencakup rangkuman materi, poin-poin penting yang dipelajari, dan pendapat pribadi penulis tentang Day 1 Proyek Workshop.

## Tujuan Repository

1. Memenuhi tugas dokumentasi Day 1 workshop sesuai ketentuan panitia.
2. Menjadi arsip catatan belajar pribadi yang bisa dibuka kembali kapan saja.
3. Menjadi latihan pertama menggunakan Git dan GitHub: membuat repository, menulis `README.md` dengan Markdown, dan mengelola dokumentasi dalam satu repo.
4. Menjadi bagian awal dari portofolio digital di GitHub.
