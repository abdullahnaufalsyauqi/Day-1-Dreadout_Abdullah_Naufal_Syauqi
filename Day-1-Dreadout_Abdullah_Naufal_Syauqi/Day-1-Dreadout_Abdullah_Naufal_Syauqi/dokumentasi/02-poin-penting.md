# Poin Penting dan Pengetahuan Baru

## Poin Penting dari Day 1

1. **MBKM memberi hak belajar di luar program studi**, dengan 8 bentuk kegiatan yang bisa dikonversi menjadi SKS. MSIB adalah salah satu jalurnya, yaitu magang atau studi independen selama 1 semester dengan sertifikat.
2. **PjBL, PBL, dan CBL itu berbeda.** PjBL menghasilkan karya nyata, PBL memecahkan masalah terbuka, dan CBL menganalisis kasus yang sudah tersedia.
3. **Kualitas jawaban AI bergantung pada kualitas prompt.** Prompt yang baik memuat Role, Task, Context, dan Format.
4. **Git dan GitHub itu berbeda.** Git adalah alat version control yang berjalan lokal, sedangkan GitHub adalah platform online untuk menyimpan repository dan berkolaborasi.
5. **Git punya tiga area:** working directory, staging area, dan repository. Perubahan harus melewati `add` lalu `commit` sebelum tersimpan.
6. **Commit dan push rutin itu penting** karena setiap perubahan tercatat (siapa, kapan, apa) dan bisa ditelusuri kembali.
7. **Dokumentasi yang rapi** sama pentingnya dengan kodenya. `README.md` adalah wajah sebuah repository.

## Pengetahuan Baru yang Saya Pelajari

- Cara menyusun prompt terstruktur (Role, Task, Context, Format) dan alasan konteks membuat hasil AI lebih baik.
- Alur kerja Git: working directory → staging area → repository.
- Perintah dasar Git: `init`, `clone`, `add`, `commit`, `remote add`, `push`, `pull`.
- Perbedaan `git add --all`, `git add -A`, `git add .`, dan `git add *`.
- Cara setup Git: identitas (`user.name` dan `user.email`), VS Code, dan SSH key (`ed25519`) untuk koneksi aman ke GitHub.
- Cara menulis dokumentasi dengan Markdown dan menyusunnya dalam satu repository.
- Gambaran program MBKM, MSIB, dan metode pembelajaran PjBL, PBL, CBL.

## Hal yang Masih Ingin Saya Pelajari

- Konsep branch dan pull request untuk kerja kolaborasi.
- Cara menyelesaikan merge conflict.
- Cara menyusun prompt yang lebih kompleks untuk membuat aplikasi yang lebih besar.
